# 数据层已知限制

本页记录截至 2026-08-09 已确认但尚未关闭的限制。它用于防止把“接口存在”误写为“生产质量已验收”。

## 1. 质量与数据

- 当前中国大陆演示库用于联调和可视化，关系仍是 Candidate，不能作为投资事实；
- 原生/扫描PDF字符错误率、TEDS、实体F1、链接准确率、关系F1和冲突召回率尚未用正式 Gold 集验收；
- 31项来源是受控来源目录，不表示31项都支持稳定批量API；有访问保护的官网必须人工导出；
- `public_access` 不等于允许再分发，正式公开快照仍需逐来源许可审核；
- 真实授权研报和电话会议音频不随仓库分发，需要团队自行提供合法样本。

## 2. 解析与抽取

- Docling、PaddleOCR、faster-whisper、pyannote 和 Transformers 属于可选重型依赖；未安装时会使用可用基线或明确失败；
- 图表数值抽取低置信度时保留 `null`，当前不保证所有复杂图表可结构化；
- 自动实体消歧可能产生同名实体合并、盐型/剂型混淆和关系自环，必须通过人工复核；
- 动态网页正文变化会生成新文档版本，版本数不能直接当作唯一文档数。

## 3. 存储与接口

- GraphQL 当前只提供公开范围读取；团队内部数据使用带内部密钥的 REST 接口；
- Neo4j、Milvus、TimescaleDB 和 Elasticsearch 的正式在线重建需要完整 Docker 服务和真实数据验收；
- 本机 CLI 默认使用 SQLite；PostgreSQL 的并发任务锁语义只能在 Compose 或真实 PostgreSQL 中验证；
- 看板读取统一事实库，不代表四类投影服务处于健康状态。

## 4. 工程检查

- `pytest`、Ruff、文档链接、研究CSV接口和 Compose 配置检查当前通过；
- 全量 `mypy src` 尚未通过，主要涉及可选依赖缺少类型存根，以及解析器、投影器和主库仓储的旧类型标注；
- 修改 Python 模块时应至少对改动路径运行定向 mypy，并把全量严格类型检查作为发布前待清理项。

该限制关闭后，应在同一提交中更新本页、对应测试和[数据层验收说明](acceptance.md)。
