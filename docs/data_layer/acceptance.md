# 数据层验收说明

仓库自动化测试覆盖以下内容：

- 数据契约与字段校验；
- 来源隔离、许可状态和访问权限过滤；
- 公开数据快照的权限隔离；
- 文件解析路由、原生 PDF 坐标和完整 JSON 保留；
- MinerU 视觉裁剪归档、临床管线颜色/条形终点/阶段列结构化、视觉硬门和推理证据接口；
- 财务单元格、实体、关系与原始证据的关联；
- 冲突保留、幂等重处理和人工复核门禁；
- Outbox 投影分发；
- REST、GraphQL、CLI、Alembic 与全部 Compose 配置。
- Metric Ontology、Claim Graph 权限过滤、Evidence Gate 四动作、Compare/Summarize 同源输出；
- 授权行情清单的默认受限权限与 TimescaleDB 行情路由。

以下指标必须使用项目自有或已获授权的 Gold 语料验证，不能只靠合成测试替代：

- 扫描 PDF 字符错误率与表格 TEDS；
- 视觉 Gold 集的资产覆盖率、管线行匹配率、阶段准确率、颜色/地区保留率和证据框 IoU；
- 实体抽取、实体链接、关系抽取、日期、单位与冲突检测指标；
- 真实电话会议的语音识别、说话人分离和身份确认；
- Neo4j、Milvus、TimescaleDB 与 Elasticsearch 的在线重建；
- 授权研报导入和公开快照泄漏审计。

只有“自动化测试报告”和“Gold 语料验收报告”均通过后，才可创建 `data-layer-v1.0.0` 标签。签字版验收结果应保存为数据集快照清单；受版权保护的原始研报和录音不得进入 Git。

数据层标签通过仍不等于整个正式研究目标完成。研究冻结、智能体对照实验和 3—5 个正式案例还必须通过[正式研究目标符合性与验收矩阵](../formal_goal_traceability.md)中的 G5、G6。

当前尚未关闭的质量、可选依赖和类型检查问题见[数据层已知限制](known_limitations.md)。已知限制未关闭时，不得只根据自动化测试通过创建正式标签。
