# 第一阶段：文献调研与研究设计冻结计划（6 周）

## 1. 阶段定位

本阶段不开发爬虫、PDF 解析器、数据库或 Agent 代码。目标是通过“系统映射研究 + 核心论文深读”，为后续数据层、知识层、Compare Agent、Summarize Agent 和评测体系建立可追溯的研究依据。

研究基线来自项目立项材料提出的 Metric Ontology、Claim Graph、Evidence Gate、Compare Agent 与 Summarize Agent。检索冻结日期为 2026-08-04，执行启动日期为 2026-08-05。

## 2. 阶段目标

六周内完成：

- 可复现的检索、筛选、质量评价和证据综合工作流；
- 不少于 100 篇文献的证据矩阵；
- 不少于 40 篇核心论文的结构化深读卡片；
- 15 篇锚点论文的双人交叉复核；
- 数据层与 Agent 研究所需的任务、指标、数据、基线和消融方案冻结；
- 第二阶段数据层输入包，但不进入数据层开发。

## 3. 核心研究问题

| 编号 | 研究问题 | 项目输出 |
|---|---|---|
| RQ1 | 投研报告、金融问答与金融摘要应如何评价？ | Compare/Summarize 多维指标体系 |
| RQ2 | 数据集与方法论文如何描述数据、实验和复现性？ | 数据集论文与实验报告模板 |
| RQ3 | 金融比较如何保证对象对齐、维度完整和结论可追溯？ | Compare DSL、比较指标与错误分类 |
| RQ4 | 如何评价摘要事实一致性、数字准确性和证据充分性？ | Claim Graph 与 Evidence Gate 指标 |
| RQ5 | 知识图谱、指标本体和分层检索应如何设计？ | Metric Ontology 与层级原则 |
| RQ6 | 金融 PDF 的文本、表格、图形和脚注如何解析和评测？ | 解析器基准与 Gold PDF 标注方案 |
| RQ7 | Agent 及多 Agent 系统如何评价过程、工具使用和协作？ | 过程指标、恢复指标和消融方案 |
| RQ8 | 现有研究的主要空白是什么？ | 创新点、研究假设和实验设计 |

## 4. 初始研究假设

1. 投研质量需要分解为检索、事实、数字推理、证据归因、信息完整性和跨文档一致性，不能压缩为单一分数。
2. 比较任务必须独立评价对象识别、口径和时间对齐、维度覆盖、差异结论、证据支持与不可比项识别。
3. Summarize Agent 必须显式输出共识、分歧、口径/时间冲突和待验证主张。
4. 分层知识图谱必须与纯向量、元数据过滤和扁平图基线比较，并报告随机性和稳定性。
5. Agent 评价必须包含里程碑、工具调用、证据使用、错误恢复、成本和时延等过程指标。
6. 数据集研究必须披露来源、许可、采样、清洗、标注、划分、泄漏、版本、局限和维护策略。

以上内容均为待系统检索验证的假设，不是阶段完成结论。

## 5. 文献调研工作流

固定流程：

`研究问题 → 检索协议 → 试检索 → 正式检索 → 去重 → 初筛 → 全文筛选 → 滚雪球 → 质量评价 → 证据提取 → 专题综合 → 决策冻结`

方法采用系统映射研究与重点深读，不声称进行医学意义上的 Meta 分析。PRISMA 记录流程数量，PRISMA-S 记录检索，Kitchenham 软件工程综述框架组织计划、实施和报告。

### 5.1 主题簇与目标

| 簇 | 内容 | 矩阵目标 | 深读目标 |
|---|---|---:|---:|
| A | 系统综述、数据集与方法论文写作 | 12–18 | 5 |
| B | 金融文档、表格和数值推理 | 18–25 | 7 |
| C | 比较推理与跨实体分析 | 12–18 | 6 |
| D | 金融摘要、事实、引用与冲突 | 18–25 | 7 |
| E | 知识图谱、本体和分层检索 | 18–25 | 7 |
| F | PDF 版面、表格、图形与脚注 | 12–18 | 4 |
| G | Agent 架构、评测和消融 | 15–22 | 6 |

### 5.2 检索范围

- 主要年份：2018-01-01 至 2026-08-04；基础性标准不设起始年。
- 语言：中文、英文。
- 首选来源：ACL Anthology、NeurIPS、ICLR/OpenReview、ACM、IEEE、PubMed、Web of Science、Scopus、arXiv、Semantic Scholar、Crossref、CNKI、万方以及 W3C/NLM 等官方规范。
- 付费全文不可访问时只记录元数据，不绕过访问控制。

检索式、数据库改写规则和种子召回要求见 `research/search/query_catalog.md`。

### 5.3 筛选与质量控制

- 50 篇校准样本；标题/摘要阶段至少 25% 双人复核；全文决定与锚点论文 100% 双人复核。
- Cohen's κ 目标不低于 0.70；不达标则停止筛选、修订规则并重新校准。
- 全文排除必须使用标准原因代码。
- 对锚点论文执行前向、后向和作者滚雪球。
- 质量按 7 个维度各 0–2 分，总分 14 分：11–14 核心证据，8–10 补充证据，0–7 只作背景。

详细规则见 `research/protocol.md`。

## 6. 六周进度与退出门

| 周 | 核心任务 | 退出条件 |
|---|---|---|
| 1 | 协议、种子集、试检索、50 篇校准、Git 初始化 | 种子召回 100%；κ≥0.70；协议确认 |
| 2 | 正式检索、合并与去重 | 400–800 条候选；每个 RQ 至少两个来源；去重抽查错误率<2% |
| 3 | 标题/摘要、全文筛选与滚雪球 | 100–140 篇候选；排除原因完整；分歧裁决完成 |
| 4 | 40 篇核心深读、15 篇锚点复核 | 深读通过复核；关键字段缺失率<5% |
| 5 | 七主题综合、指标/基线/错误库、研究假设 | 每项机制≥3篇独立证据且有反例/局限；指标可操作化 |
| 6 | 决策冻结、第二阶段输入包、阶段验收 | 矩阵≥100；深读≥40；决策已关闭或标记待实验 |
