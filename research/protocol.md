# 系统映射研究执行协议 v2.0

本文件规定“具体怎么做”。阶段总计划规定“为什么做、何时完成、交付什么”。

## 1. 基本信息

- 执行周期：2026-08-05—2026-09-15
- 文献检索截止：2026-08-04
- 方法：系统映射研究 + 核心论文深读
- 语言：中文、英文
- 规范：PRISMA 2020、PRISMA-S、Kitchenham & Charters、Wohlin滚雪球方法

协议冻结后不得直接修改历史规则。任何变化先写入 `protocol_deviations.csv`。

## 2. 文献记录生命周期

| 状态 | 含义 | 进入条件 | 下一步 |
|---|---|---|---|
| `identified` | 由检索或滚雪球发现 | 有标题和来源 | 去重 |
| `deduplicated` | 已确认不是重复记录 | DOI/来源ID/标题检查完成 | 标题摘要筛选 |
| `title_abstract_include` | 初筛保留 | 至少对应一个RQ | 获取全文 |
| `title_abstract_exclude` | 初筛排除 | 明确不符合范围 | 记录理由后结束 |
| `borderline` | 信息不足 | 暂时无法判断 | 第二人复核或查全文 |
| `fulltext_include` | 全文纳入 | 两人同意或已裁决 | 质量评价 |
| `fulltext_exclude` | 全文排除 | 有E01—E10原因码 | 更新PRISMA |
| `quality_scored` | 质量评分完成 | 两人给出一致分数 | 证据提取 |
| `extracted` | 矩阵字段已填写 | 关键字段齐全 | 第二人核验 |
| `verified` | 主要结论已对照全文 | 数字和原文定位确认 | 主题综合 |
| `synthesized` | 已进入综合结论 | 关联综合编号和决策 | 阶段验收 |

## 3. 检索协议

### 3.1 数据源分工

| 类型 | 数据源 | 主要负责主题 |
|---|---|---|
| NLP与金融文档 | ACL Anthology、arXiv | B、C、D、G |
| AI与Agent | NeurIPS、ICLR/OpenReview、ACM、IEEE | E、F、G |
| 医药与临床信息学 | PubMed、Web of Science、Scopus | E、F及医药迁移研究 |
| 综合补充 | Semantic Scholar、Crossref | A—G、版本和引用检查 |
| 中文研究 | CNKI、万方 | B—G |
| 官方标准 | W3C、NLM、ClinicalTrials.gov | A、E、F |

每个RQ至少同时覆盖：

- 1个同行评审主来源；
- 1个综合索引或官方来源。

### 3.2 检索范围

- 主要年份：2018-01-01—2026-08-04；
- 基础标准和经典方法：不设起始年；
- 中文与英文分别检索；
- 预印本仅在没有正式版本或研究很新时作为主记录。

### 3.3 每次查询必须记录

在 `search_log.csv` 中填写：

```text
search_id
topic_cluster
database
query_version
actual_query
date_run
date_from
date_to
language
result_count
export_file
export_sha256
operator
status
notes
```

状态只允许：`not_run`、`pilot_failed`、`pilot_passed`、`formal_complete`、`superseded`。

修改查询式时新增一行和新版本号，不覆盖旧记录。

### 3.4 种子召回测试

1. 以 `seed_set.csv` 中 `is_seed=true` 的记录为测试集；
2. 在预先声明的数据库组合中执行试检索；
3. 为每篇种子填写 `search_hit_source`；
4. 计算：`已召回种子数 / 全部种子数`；
5. 结果必须为100%；
6. 未召回时检查同义词、短语、字段限制和数据库覆盖，修改后重新测试。

100%要求针对“数据库组合”，不要求每一个数据库单独召回全部跨学科论文。

## 4. 合并与去重

### 4.1 去重顺序

1. DOI完全相同；
2. ACL、PubMed、arXiv等来源ID完全相同；
3. 标题转小写、去标点和多余空格后相同；
4. 规范标题高度相似，且第一作者和年份相同。

### 4.2 版本规则

- 正式会议/期刊版本优先；
- 预印本保留为关联版本，不作为第二条独立证据；
- 扩展期刊版和会议版只有在数据或方法有实质差异时才分别保留；
- 无法自动判断时标记 `manual_dedup_required`。

### 4.3 编号

去重完成后分配：`LIT-YYYY-NNN`。

编号一旦提交Git不得复用；论文排除后也保留原编号。

## 5. 筛选协议

### 5.1 纳入条件

候选文献必须：

1. 至少直接回答RQ1—RQ8中的一个；
2. 提供方法、数据集、指标、实验、误差分析或权威规范中的至少一种；
3. 作者、来源和版本可确认；
4. 能获得足够信息进行评价。

### 5.2 排除原因

| 代码 | 使用条件 |
|---|---|
| E01 | 与RQ1—RQ8均无直接关系 |
| E02 | 只有宣传、新闻或观点，没有方法/数据 |
| E03 | 纯股价预测，不涉及文档理解或投研推理 |
| E04 | 纯临床诊断，无法迁移到投研任务 |
| E05 | 重复记录或已有更正式版本 |
| E06 | 作者、来源或版本无法确认 |
| E07 | 正文信息不足或全文无法获得 |
| E08 | 非中文/英文且无可靠译文 |
| E09 | 已撤稿或存在重大研究完整性问题 |
| E10 | 其他；必须写明具体原因 |

全文排除不得只写“无关”。

### 5.3 50篇校准

校准样本应包含：

- 七主题均有论文；
- 明显纳入、明显排除和边界论文；
- 同题不同版本；
- 只提供元数据或全文不足的记录；
- 中文和英文论文。

5名成员独立判断，不提前讨论答案。计算所有主审—复核组合的两两Cohen's κ。

通过条件：

- 平均κ≥0.70；
- 任一实际复核对κ≥0.60；
- 所有高频分歧都已转化为书面规则。

未通过时重新修订规则，并用新的边界样本开展下一轮校准。

### 5.4 正式筛选

- 标题/摘要：主审处理全部记录，随机25%由第二人独立复核；
- 全文：100%双人独立判断；
- 分歧：第三人裁决；
- `borderline`：查全文或交第二人，不得直接排除；
- 所有决定记录执行人、日期、阶段和理由。

## 6. 质量评价

### 6.1 七项评分

| 项目 | 0分 | 1分 | 2分 |
|---|---|---|---|
| 任务定义 | 不清楚 | 基本可理解 | 输入、输出和边界完整 |
| 数据来源 | 未说明 | 部分说明 | 来源、许可、采样完整 |
| 方法描述 | 无法复现 | 描述主要步骤 | 流程、参数和实现细节充分 |
| 基线 | 没有或明显不公平 | 基线有限 | 强基线且比较公平 |
| 指标 | 与任务不匹配 | 只覆盖部分能力 | 覆盖主要任务目标 |
| 实验可信度 | 缺少关键分析 | 有部分消融/误差分析 | 消融、统计和误差分析充分 |
| 开放与局限 | 均未说明 | 说明其中一项 | 开放状态和局限均清楚 |

### 6.2 证据等级

- 11—14：`core`；
- 8—10：`supplementary`；
- 0—7：`background`；
- 官方规范：`foundational_standard`。

两人独立评分后形成一致分数，不取简单平均。总分相差>2，或任一单项相差2时必须讨论。

## 7. 证据提取

### 7.1 矩阵必填字段

进入综合的论文至少填写：

- ID、标题、作者、年份、来源和链接；
- 主题和RQ；
- 任务定义；
- 数据来源、规模和许可状态；
- 输入形式；
- 方法和基线；
- 指标和主要结果；
- 消融、错误类型和局限；
- 项目组件和设计含义；
- 质量分、证据等级和复核状态。

原文没有说明时留空，并在卡片中写“作者未报告”；不得自行补造。

### 7.2 深读卡片状态

- `draft`：第一人阅读中；
- `primary_complete`：第一人已完成；
- `review_changes_requested`：第二人要求修改；
- `full_text_verified`：第二人已核验；
- `synthesized`：已进入综合。

LLM可辅助形成草稿，但论文主张、实验数字和原文位置必须人工核对。

## 8. 滚雪球

对15篇锚点执行：

- 后向：检查参考文献；
- 前向：检查引用该论文的后续研究；
- 作者：检查同一团队的相关数据集或改进版本。

滚雪球论文必须重新经过去重、标题摘要筛选和全文筛选，不得因“被锚点引用”直接纳入。

当连续两轮滚雪球没有发现新的可纳入论文时，该主题可停止滚雪球。

## 9. 证据综合

每条综合结论必须包含：

```text
synthesis_id
结论
支持文献ID（至少3篇）
反例或局限文献ID（至少1篇）
适用任务与条件
对本项目的影响
关联决策D01—D10
置信度
```

不得直接平均任务、数据集或指标定义不同的实验数字。

## 10. 决策冻结

决策状态只允许：

- `open`：证据尚未整理；
- `evidence_review`：正在比较文献方案；
- `experiment_required`：必须由第二阶段实验决定；
- `frozen`：方案和边界已经确定；
- `rejected`：候选方案已排除。

`frozen`必须同时具备：候选方案、支持证据、反例/局限、模拟任务结果、采用理由、风险、批准人和日期。

## 11. 文件与版权

- 不提交未授权PDF、付费论文或券商研报；
- 原始导出放在Git忽略目录，只提交日志和哈希；
- 只保存必要的短摘录和页码定位，不大段复制论文正文；
- 无法访问全文时只记录元数据状态；
- 不绕过登录、付费墙、验证码或频率限制。

## 12. 阶段验收

只有以下条件全部满足，才能合并到 `main` 并创建 `research-phase1-v1.0`：

- 种子组合召回率100%；
- 校准平均两两κ≥0.70，任一复核对≥0.60；
- 证据矩阵≥100篇；
- 深读卡片≥40篇；
- 15篇锚点全部双人复核；
- 关键字段缺失率<5%；
- D01—D10全部有明确状态；
- 第二阶段数据需求完整；
- `scripts/validate_phase1.ps1`通过；
- 工作区无未提交修改。
