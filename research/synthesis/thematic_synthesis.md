# 七主题证据综合

> 当前状态：结构化模板。证据矩阵中的18条记录仅完成元数据建档；在深读卡片达到 `full_text_verified` 前，不得把候选说法写成已确认结论。

## 1. 综合规则

每条综合结论使用 `SYN-A-001` 等稳定编号，并填写：

| 字段 | 要求 |
|---|---|
| 结论 | 一句话说明发现，不使用“普遍”“显著”等无证据词 |
| 支持文献 | 至少3篇独立研究，标记同行评审/预印本/标准 |
| 挑战证据 | 至少1篇反例、负结果、局限或替代解释 |
| 适用条件 | 任务、数据、语言、模型和评价范围 |
| 项目影响 | 对数据层、Agent、指标或实验的具体约束 |
| 决策 | 关联D01—D10 |
| 置信度 | high/medium/low，并说明理由 |

禁止直接平均任务定义、数据集或指标不同的实验数字。工程演示结果必须标为“实施观察”，不能列入“论文结论”。
